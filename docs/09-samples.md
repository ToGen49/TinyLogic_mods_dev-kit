# 9. Samples worth reading

> Back to the [kit index](../readme.md) · Previous: [8. Sharing](08-sharing.md) · Next: [10. Recipes](10-recipes.md)

Shipped with the game in `<install>/assets/mods/samples/`:

| Sample | What it teaches |
|---|---|
| `board-stats` | The best first read: ask the board, draw, remember a setting |
| `bench-meter` | `tl.elec` — settings by name, volts, amps |
| `node-pack` | `tl.export` / `tl.require`, `tl.graph.node`, `tl.command` |
| `rainbow-wires` | Graph-only mod, no code |
| `party-mode` | Graph-only, timers and wire colours |
| `auto-tester` | Systematic board driving + truth tables |
| `auto-builder` | Building a circuit part by part |
| `auto-wire-colour` | Small graph reacting to `wire_added` |
| `confetti` | A graph that calls Lua |
| `gravity`, `snake`, `walk-your-circuit` | Games on the board: input capture, drawing, `vars` |

`samples/starter.txt` lists the three the game suggests first:
`board-stats auto-tester rainbow-wires`.

The kit's own [`examples/`](../examples/) are smaller and one-topic each — start
there, then read the game's samples for real-world shape.
